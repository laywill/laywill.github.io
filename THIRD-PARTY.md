`LICENSE.txt` covers the site's own content and the HTML5 UP "Story"
template it is built on (CC BY 3.0). It does not cover bundled third-party
assets, which carry their own licences and copyright notices, kept
alongside the files they cover:

| Asset                                                          | Licence          | Notice                                                            |
| ---------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------ |
| Font Awesome 4.6.3 icon fonts (`assets/fonts/FontAwesome.otf`, `assets/fonts/fontawesome-webfont.*`) | SIL OFL 1.1 | [assets/fonts/LICENSE-FontAwesome.txt](assets/fonts/LICENSE-FontAwesome.txt) |
| Font Awesome 4.6.3 CSS (`assets/css/font-awesome.min.css`)     | MIT               | [assets/fonts/LICENSE-FontAwesome.txt](assets/fonts/LICENSE-FontAwesome.txt) |

Add a row here for each new third-party asset, with its licence text
committed next to the file(s) it covers.
